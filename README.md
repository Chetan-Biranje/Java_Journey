# Java Journey

Practice programs from my first steps in Java. This is a fork of
[ntsvg/Java_Journey](https://github.com/ntsvg/Java_Journey) that I use to keep my own solutions.

| File | What it does |
|---|---|
| `EvenOdd.java` | Reads a number of test cases, then tells you whether each number is even or odd |
| `Largest_of_three.java` | Reads three integers per test case and prints the largest |

```bash
javac EvenOdd.java && java EvenOdd
```

Both use `Scanner` for input and loop over test cases, the way competitive-programming
problems are usually structured.
